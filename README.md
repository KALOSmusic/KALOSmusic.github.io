# KALOS — Prototype v0.1

This is the first from-scratch prototype of the KALOS website.

## Current prototype

- Black minimalist homepage
- Animated KALOS logo, using the two supplied logo components
- `WHO IS KALOS`
- `WORKS`
- Expandable album archive
- First album: **Lorna — Insatiable**
- `CONCEPT / AUDIO / LYRICS` tabs
- YouTube playlist link
- Responsive mobile layout

## Important

This is intentionally a prototype. The next iterations should refine:
- exact logo animation
- typography and spacing
- board/update system
- album content model
- lyrics layout and translations
- YouTube player treatment
- publishing workflow
- eventual no-code content editing
